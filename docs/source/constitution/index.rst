Constitution
============

The project constitution captures the foundational decisions that guide all
feature development. It consists of four parts:

- **Mission** — Why this project exists, who it serves
- **Decisions** — Key architectural and technology choices
- **Roadmap** — Planned features in delivery order
- **Risks** — Identified risks and mitigations
